# Be Ready by Noon

A short Wild West duel game made for **GMTK Game Jam 2026**. Plan three moves, wait for noon, then watch the shootout play out.

## How to play

1. Pick an opponent on the wanted board.
2. During planning, commit **move** or **shoot** actions.
3. When the clock hits noon, both plans resolve at once.
4. Survive the duel and clear the board.

**Miss both sides?** Time rolls over to the next noon — no restart needed.

## Controls

- **Mouse** — select tiles / confirm actions / advance dialogue
- **Space / Enter** — continue dialogue
